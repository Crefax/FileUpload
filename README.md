# Crefax Upload

Crefax Upload, dosyalarınızı güvenli bir şekilde yüklemenize ve paylaşmanıza olanak sağlayan basit ve kullanıcı dostu bir dosya paylaşım uygulamasıdır.

## Özellikler

- 🚀 Kolay dosya yükleme
- 🔒 Güvenli dosya paylaşımı
- 📱 Duyarlı tasarım (responsive design)
- 🎨 Modern ve şık arayüz
- ⚡ Hızlı indirme bağlantıları
- 🗑️ Dosya silme özelliği

## Teknolojiler

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/kullaniciadi/crefax-upload.git
```

2. Proje dizinine gidin:
```bash
cd crefax-upload
```

3. Gerekli bağımlılıkları yükleyin (eğer varsa):
```bash
npm install
```

4. Uygulamayı başlatın:
```bash
npm start
```

## Kullanım

1. Ana sayfada "Dosya Seç" butonuna tıklayın
2. Yüklemek istediğiniz dosyayı seçin
3. Dosya otomatik olarak yüklenecek ve indirme bağlantısı oluşturulacaktır
4. İndirme bağlantısını paylaşarak dosyanızı başkalarıyla paylaşabilirsiniz
